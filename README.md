## dotzsh

- Manage zsh, Git, and other dotfiles with Nix.
- Install AeroSpace and CLI tools, and configure Ghostty and other apps.

## getting started

0. `cd "$HOME"`
1. `git clone https://github.com/YuigaWada/dotfiles.git`
2. `mv dotfiles .zsh`
3. `cd .zsh`
4. `./scripts/bootstrap-nix.sh --install-nix --interactive`
